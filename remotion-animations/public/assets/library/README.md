# Biblioteca visual local

Cada colección debe vivir en una subcarpeta propia y acompañarse de un
`manifest.json` con, como mínimo:

- `id` estable;
- nombre de archivo;
- tipo y dimensiones;
- origen, autor y licencia;
- etiquetas semánticas;
- punto focal recomendado si es una imagen.

No se añaden aquí descargas automáticas ni recursos de procedencia dudosa.
